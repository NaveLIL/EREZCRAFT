# Инструкции для работы в EREZCRAFT

## Начало новой сессии

Сначала прочитай `docs/HANDOFF.md`, `README.md`, `IMPLEMENTATION_ROADMAP.md` и `docs/progress/AUTONOMOUS.md`. Проверь `git status`, HEAD и реальные результаты проверок. Файлы и текущее состояние важнее рассказа предыдущего агента. Не клонируй проект заново, если рабочая копия уже есть.

## Как работать с владельцем

- Общайся по-русски, кратко и по делу. Выполняй поручение до проверенного результата; не останавливайся на предложении плана.
- Владелец не любит повторные подтверждения. Для обычных обратимых исправлений и уже порученных этапов продолжай самостоятельно. Спрашивай только при действительно недостающем решении, конфликте требований или новом разрушительном действии.
- Перед инструментами дай короткий комментарий. Во время долгой работы сообщай значимые результаты, неопределённости и следующий проверяемый шаг; не оставляй владельца без обновления дольше минуты.
- Не выдавай подготовленную тестовую сцену за прохождение Survival. Не называй этап закрытым без доказательств его требований.
- Не делегируй другим агентам, если владелец или действующие инструкции прямо этого не разрешили.
- Не создавай новую активную цель только из привычки. Предыдущая цель M10–M12 завершена; новая цель требует прямого поручения.

## Данные и публикация

- Пользовательский игровой профиль `build/playtest` и его сохранения неприкосновенны для автоматических тестов. Не закрывай работающую игру владельца и не заменяй его мир тестовым.
- Все новые проверки — только в отдельных папках `.verification` либо специально назначенных одноразовых профилях. Нельзя очищать пользовательские миры, менять им seed или режим ради зелёного теста.
- История Git сохраняется. Не делай force push, reset чужих изменений или массовое удаление. Публикуй новые изменения только в рамках актуального поручения владельца; предыдущая публикация завершена.
- `textures/`, `.verification/`, `research/`, сборочные кеши и миры остаются локальными. Не добавляй их через `git add -f`.

## Код, ресурсы и приёмка

- Уточнение владельца для M14: новые текстуры брать готовыми из проверенных наборов; разрешена только замена палитры. Сохранять исходный рисунок, размеры и альфа-канал. Не рисовать дополнительные детали, не зеркалить/поворачивать пиксели и не исправлять края новых PNG без отдельного поручения. Формы блоков/деревьев настраиваются геометрией и данными, а не переработкой рисунка.

- Minecraft1.21.1, NeoForge21.1.252, Java21. Не обновляй версии без причины и проверки совместимости.
- Сохраняй поддержку LEGACY128 и TALL256 и договорённые границы морей/клиренс. Используй `GeometryProfile`, не переносись на старые константы128 в высоком измерении.
- Первое попадание — через аномалию обычного мира. Рамы и линза устойчивого портала требуют ресурсов Междуморья. Не возвращай рецепт полностью из внешних материалов.
- С 08.10.2026 владелец разрешил проверенную CC0-библиотеку для геологии и будущих блоков/предметов. Сохраняй палитру, 16×16, стыковку краёв и формы авторской флоры; океаны не меняй. `tools/GenerateProjectTextures.java` воспроизводит собственные элементы и документированную CC0-геологию из маленьких включённых исходников. Источники/лицензии/хеши обязательны в `docs/ASSET_LIBRARY.md` и `assets/interstice/provenance/`. Старые неизвестные архивы не возвращай.
- Материалы/блоки требуют регистрации, моделей, локализации, добычи, тегов и рецептов. Worldgen требует реального размещения; один JSON без вызова генератора не закрывает задачу.
- Проверяй изменения соответствующим риску: поведение — GameTests, сохранение — отдельный процесс, сеть/визуал — настоящий клиент. Изолируй сцены, изменяющие мир, от измерений исходной геометрии.
- Ждущий процесс сначала проверь по его живому handle/PID. Таймаут наблюдения не означает остановку. Не запускай второй экземпляр только потому, что первый долго отвечает.
- Используй короткие итерации и телеметрию. При застревании сначала зафиксируй фактическую позицию, этап, инвентарь и ошибку; не заменяй проверку всё более удобной фикстурой.
- После необходимых успешных проверок не повторяй их без новых изменений или неразрешённых сомнений. В итоговом ответе: результат, что проверено, существенные ограничения, ссылка на артефакт/отчёт.

## Технические ограничения Windows

В этой среде batch/WSH могут блокироваться политикой. Пользуйся прямым Java запуском `org.gradle.wrapper.GradleWrapperMain` или `tools/verify.py` с заданным `JAVA_HOME`; не меняй системную политику. Не смешивай оболочки для удаления/перемещения. Для рекурсивной операции сначала проверь абсолютный путь и его принадлежность рабочему каталогу.
