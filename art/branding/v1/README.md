# EREZCRAFT — Междуморье

Первый концепт утверждён владельцем21.10.2026: остров между светлым верхним и
багровым нижним морем. `concept-approved.png` сохранён без изменения. Для чистого
прозрачного экспорта подготовлена векторная адаптация и упрощённая малая иконка.
После замечания владельца поверхность нижнего моря опущена ниже острова, а волны
ограничены отдельным clipPath. Игровые океаны эта работа не меняет.

- `erezcraft-logo.svg` / `.png` — знак с названием, текст переведён в контуры.
- `erezcraft-emblem.svg` / `.png` — отдельный подробный знак.
- `erezcraft-icon-small.svg` / `.png` — упрощённый знак для малых размеров.
- `erezcraft-app-icon.png` — 1024×1024, прозрачный фон.
- `erezcraft.ico` — Windows,16/24/32/48/64/128/256px.
- `erezcraft.icns` — macOS.
- `provenance.json` — происхождение, статус и SHA256 всех файлов.

PNG получены прямым рендером SVG в Chromium. Alpha проверена: прозрачные углы,
воздушные зазоры над/под островом, отсутствие красной воды выше заданной поверхности.
ICO/ICNS — преобразования формата готовой иконки. Нет внешних шрифтов, ссылок или
растровых вставок в SVG; мастер остаётся редактируемым и масштабируемым.

Эти материалы пока локальны: они не добавлены в опубликованную alpha.16 и не
заменяют ассеты установленного лаунчера0.4.6. Следующая фаза — отдельные макеты
главного меню/загрузки и применение бренда в лаунчере. Новая версия оформления
доставляется обычным подписанным обновлением после проверки.
