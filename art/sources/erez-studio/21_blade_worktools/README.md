# Blade / EREZ worktools — B01

Автор исходных моделей: TimmyChips, Blade — Held Items 1.0.1 (CC0-1.0), Modrinth QtFiEb3u / LLyZvI13. Закреплённый ZIP: `D:/repos/Blender/catalog/blade_held_items/blade-held-items-resourcepack_1.0.1.zip`; SHA-256 b886506212c0efd5f5ad524f24a046b19f7a38ad0245bcc6a5c88c3b66e705a7. Лицензия и снимок метаданных: `D:/repos/Minecraft/EREZCRAFT/art/sources/cc0/blade-held-items/`.

Восемь адаптированных предметов: pickaxe, axe, shovel, hoe × riftsilver/riftsteel. Не изменены исходные элементы, вращения, грани, UV-развёртки и позы удержания Blade. Оставлены 16×16 и исходный альфа-канал. Палитра серебра — прежняя сиренево-серебристая, рифтстали — тёмная сине-серая; древесина сохраняет исходный рисунок. Добавлена только поза GUI для объёмной миниатюры. Мечи, броня и механика инструментов не меняются.

Канонический источник геометрии — закреплённые JSON `template_*` в исходном ZIP. `source/blade_worktools_B01.json` — воспроизводимый снимок адаптации. Единицы: 16 model units = 1 игровой блок. Blender/GLB — визуализация тех же элементов, без модификаторов.

Сборка ресурсов: `D:/repos/Minecraft/EREZCRAFT/tools/build_blade_worktools.py`. Проверка ресурсов: `tools/verify_blade_worktools.py` в Minecraft-проекте. Сцена: `assembly/blade_worktools_B01.blend`; превью: `preview/blade_worktools_B01.png`; восемь GLB — в `exports/`. Игровые проверки и готовность публикации отмечаются в итоговом отчёте; Blender-рендер не подтверждает хват в игре.
