Снято 27.10.2026 в Minecraft Java 1.21.1, NeoForge 21.1.252, полной клиентской сборке из 106 модов с Distant Horizons. Версия мода: `0.7.0-preview.18-armor`. Все 12 PNG — исходные снимки игры 1920×1080 без обработки.

В кадре три тестовых игрока, которые отображаются обычным клиентом как `RemotePlayer`: EREZ_Silver, EREZ_Steel и EREZ_Magen. У двух игроков обычные руки Steve, у стального комплекта узкие руки Alex. Использованы локальные ванильные скины.
