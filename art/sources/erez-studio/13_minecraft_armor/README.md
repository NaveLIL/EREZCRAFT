# Междуморье — объёмная броня и «Маген»

Реализована локальная версия `0.7.0-preview.18-armor` для Minecraft Java 1.21.1 / NeoForge 21.1.252.
Два согласованных комплекта получили объёмные модели и усиления. Добавлена силовая броня «Маген» со звездой Давида, новый композит, электроника, локальный сканер и питание от гравитационного поля Междуморья.

- Геометрия всех трёх комплектов: `source/armor_design_A04.json`; два одобренных комплекта A01 сохранены без изменения их геометрии.
- Исходники игры и полное описание характеристик/крафтов: `D:/repos/Minecraft/EREZCRAFT/docs/ARMOR.md`.
- Готовый JAR: `exports/interstice-0.7.0-preview.18-armor.jar`; рядом исходный JAR.
- Актуальные снимки в игре: [галерея A04](preview/player_gallery/README.md). Исторические карточки A03: `preview/magen_review_A03.png`, `preview/three_armor_sets_A03.png`.
- Blender: `assembly/mezhdumorye_magen_A04.blend`; две исходные модели остаются в `assembly/mezhdumorye_armor_A01.blend`.
- Требования и решения: `source/requirements.json`; проверка A04: `reports/player_gallery/accepted.json`; историческая интеграция версии 17: `reports/integration.json`.

Проверены 23 игровые проверки, 68 проверок инструмента запуска, сборка и два разных запуска полной сборки с DH/106 зарегистрированными модами. В игре проверены модели, ночное зрение, локальные цветные контуры за стеной, сохранение обычного зелья и холодное сохранение энергии/износа/имени предмета. Код и ресурсы JAR соответствуют проверенному кандидату. Подготовленные сцены не заменяют длительный естественный Survival и проверку каждого стороннего шейдера.

Авторитетный источник формы — JSON A04. Нативная копия этого файла подключена через NeoForge к шести штатным костям и слотам брони. Новая геометрия не заменяет скин игрока. Стандартные текстуры Minecraft читаются по игровым ID; их PNG в мод не включены. Иконки электроники и новой брони — неизменённые CC-BY-4.0 текстуры Malcolm Riley, с атрибуцией и контрольными суммами.

На сервер и в пользовательские профили эта версия не устанавливалась. Для сетевой игры клиент и сервер должны использовать согласованную версию мода. Старый и длинный мечи сохранены. Незавершённые изменения фауны не включены в JAR.

История A01 и первоначальный вариант A02 сохранены. Для повторной генерации формы: `tools/build_aegis_design.py`; для рендера: `tools/render_aegis.py`; для карточек: `tools/compose_magen.py`. Сцену .blend не следует считать отдельным редактируемым источником игровой формы.


Игровая проверка A04: `preview/player_gallery/README.md`, 12 кадров без обработки; `reports/player_gallery/accepted.json`. У Магена закрыты просветы под шлемом и на поясе; остальные комплекты и игровой код сохранены. Актуальную форму A04 воспроизводит `tools/build_magen_seals.py`, Blender-сцену — `tools/render_magen_A04.py`.
