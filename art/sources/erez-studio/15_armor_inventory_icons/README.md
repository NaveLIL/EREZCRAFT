# Миниатюры всей брони EREZ

Версия `0.7.0-preview.20-icons`: 16 отдельных объёмных миниатюр для серебряной брони, рифтстали, Магена и Котомяфа. Геометрия предметов получена из тех же кубов, костей и точных углов поворота, что используются надетой бронёй. У курток показаны оба рукава, у поножей и обуви — обе ноги. Котомяф соответствует окончательному варианту **без мордочки и хвоста**.

Авторитетная геометрия остаётся в проектах 13 и 14. [Манифест источников, кубов и контрольных сумм](source/icon_manifest.json) фиксирует происхождение каждого из 16 производных item-моделей. Новые PNG не рисовались. Загрузчик NeoForge запекает точные грани один раз; затем Minecraft рисует их обычным ItemRenderer в инвентаре, руке, рамке и на земле. Палитра и игровые текстуры материалов совпадают с надетой бронёй. Окраска меняет основной материал; прочие элементы сохраняют цвет. Блеск зачарования использует штатный проход игры.

Клиентские изменения не меняют защиту, способности, рецепты, звуки, модели надетой брони или старый/длинный мечи. Все прежние runtime-классы проверяются на идентичность версии 19. Новый загрузчик и обработчики цвета находятся только на клиентской стороне. Установочные профили и сервер этой задачей не обновляются.

Игровые снимки:

- `preview/armor-icons-inventory.png` — настоящий экран инвентаря Survival; наборы идут по рядам: серебро, рифтсталь, Маген, Котомяф в хотбаре.
- `preview/armor-icons-catalog.png` — диагностическая витрина с увеличенными иконками, нарисованными тем же игровым ItemRenderer; это не составной рендер Blender.
- `preview/armor-icons-after-reload.png` — повторная проверка после полной перезагрузки ресурсов.
- `preview/armor-icons-dye-glint.png` — окрашенный серебряный нагрудник и зачарованный нагрудник Магена.

Скриншоты сохраняются без обработки в 1920×1080. Локальные тестовые сцены не являются прохождением Survival или нагрузочным тестом сервера. Подробности — `reports/accepted.json`.

Генератор: `tools/build_icons.py`. Полученные игровые JSON — `exports/models/item/`. Предыдущие генераторы ресурсов сохраняют модели с загрузчиком `interstice:armor_icon`; для изменения формы миниатюр следует повторно запускать этот генератор после изменения исходной геометрии.
