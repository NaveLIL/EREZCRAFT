# Решения владельца по NE01

Основа — реальное судно Nordhavn 96. Нужны жилые помещения, свободные проходы,
управление и одна настоящая МЕ-сеть с несколькими терминалами.

Особый приоритет — отсутствие просветов между панелями и вокруг стекла.
Корпус выполнен непрерывной оболочкой; стёкла заходят под цельные рамы.
При экспорте поверхности разделяются по границам блоков с точной привязкой 0/1.

Владелец отдельно разрешил собственные текстуры для нового корабля.
Для NE01 созданы 19 исходных текстур без заимствованных пикселей Minecraft
или фотографий производителя. Ограничение прежнего задания M14 к ним не относится.

29.10.2026: сначала владелец выбрал «Пока играю, продолжай модель».
Затем сообщил «Майн я закрыл». Перед запуском отдельной проверки AE2/Sable
проверка процессов подтвердила отсутствие игрового клиента.
Проверки используют только .verification/ne01me*; пользовательские миры не затронуты.

Blender-модель и её анимация не подтверждают игровую коллизию, работу механизмов,
морскую тягу или возможность сна на движущемся корабле. Эти требования остаются
отдельными проверками настоящего клиента с DH.
