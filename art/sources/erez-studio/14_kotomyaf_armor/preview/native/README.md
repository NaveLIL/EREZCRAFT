Это постановочная проверка трёх серверных тестовых игроков с имитированными соединениями и одного настоящего клиента наблюдателя. Она проверяет штатное отображение игроков, позы, звук и поведение мобов; длительное прохождение Survival и ёмкость сетевого сервера ею не подтверждаются.
