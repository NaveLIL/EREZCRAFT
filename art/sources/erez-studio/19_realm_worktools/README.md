# EREZ — рабочие инструменты Междуморья / WT03

Восемь объёмных инструментов: серебряные и рифтстальные кирка, топор, лопата и мотыга. WT01 отклонён за кривую и разорванную форму. WT02 стал связным, но пользователь потребовал более узкую и плавную форму, исправить положение в руках. WT03: кирка уже на25%, криволинейные профили по сетке0,5 единицы и согласованные повороты для прямой3D-рукояти вместо диагонального ванильного спрайта. Форма остаётся кандидатом на визуальную приёмку.

Авторитетная геометрия: `source/worktools_WT03.json`, раздел `models`. Эта геометрия без сглаживания и дополнительных фасок переносится в Blender и в обычные модели Minecraft Java 1.21.1. Единицы —16 единиц модели на один игровой блок. Освещение Blender отличается от игрового.

## Управление и свойства

| Материал / инструмент | Свойство |
| --- | --- |
| Все серебряные | +25% к **базовой** скорости добычи подходящих местных природных материалов из явного тега. Уровень добычи остаётся железным. Бонус не означает ровно +25% к общей скорости с зачарованиями. |
| Рифтстальная кирка | Переключаемая выработка 3×3 по выбранной грани, по списку камня. Дополнительные руды, сундуки и другие блоки с сущностью блока не затрагиваются. |
| Рифтстальный топор | До 16 связанных необтёсанных брёвен одной породы за сруб, включая первое. Распространение по шести соседям от места сруба вверх; листва и доски не затрагиваются. Это обработка брёвен, а не безошибочное распознавание природного дерева. |
| Рифтстальная лопата | Переключаемая расчистка грунта 3×3 по выбранной грани. |
| Рифтстальная мотыга | ПКМ обрабатывает грядку 3×3, в том числе корневой суглинок и местный дёрн. Закрытая сверху или запрещённая почва пропускается. |

Новые инструменты по умолчанию одиночные. **Shift + ПКМ по воздуху** переключает режим рифтстали. Приседание во время работы временно делает её одиночной, не сбрасывая сохранённый режим. Текущий режим есть в подсказке; переключение выводит сообщение над панелью предметов. Данные хранятся в самом предмете и переживают сохранение мира, не заменяя имя, износ и другие данные.

Прочность расходуется обычным игровым способом за каждый блок. Прочность, эффективность, удача, шёлковое касание и починка используют существующие механизмы Minecraft. Кирка и лопата обрабатывают только блоки в обычной досягаемости. У топора продолжение сруба может идти выше обычной досягаемости: до 15 блоков вверх и до 4 по каждой горизонтальной оси от исходного сруба; максимум 16 брёвен. Первый сруб всегда требует обычной досягаемости.

Для дополнительных блоков проверяются загруженный чанк, граница мира, разрешение взаимодействия и режим Survival. Разрушение вызывает обычное отменяемое событие добычи и обычный расчёт добычи. Обработка грядки проходит отдельные события ПКМ для каждого блока. Чанки ради массовой работы не загружаются. Сломавшийся или сменённый инструмент останавливает продолжение. Creative и Adventure не включают массовую работу.

Базовые характеристики, стоимость крафта, материалы ремонта и оба меча сохранены. Приборы из проекта 18 в этой итерации не меняются.

## Воспроизведение

`tools/build_design.py` создаёт геометрию и палитры. `tools/prepare_blender.py` формирует скрипт импорта; запуск `tools/build_blender.py` через Blender в фоновом режиме сохраняет `.blend`, GLB и Cycles-рендеры. `tools/verify_design.py` проверяет геометрию. `tools/prepare_candidate.py`, `tools/build_game_resources.py` и `source/code/` описывают игровой кандидат; не запускать подготовку поверх иной версии без сверки базы. `tools/prepare_native.py`, `tools/run_native.py --run-id NN` создают новый изолированный профиль и снимают фактическую игру. Ни один из этих шагов не публикует версию.
