# EREZ studio handoff source snapshots

Start with `../../../docs/HANDOFF_EREZ_STUDIO.md` and
`../../../docs/verification/EREZ_STUDIO_HANDOFF.json`.

These are preserved source snapshots for review and selective integration, not
active source sets and not a replacement for the primary working tree.

- Project18: preview.22 delta against its recorded preview.21 baseline.
- Project19: preview.23 WT03 code/resources, patch and evidence.
- Project20: preview.24 E11 code/resources, authoritative mesh, Blender source,
  D02 gameplay proposal, native evidence and material provenance.

Canonical authored projects remain in `D:/repos/Blender/creations/`.
The complete private local archive of projects12–20 is at
`art/generated/erez-studio-handoff/EREZ_STUDIO_2026-10-27_FULL.zip` under the
Minecraft repository. It is intentionally ignored by Git and is not published.

D02 self-charging and closed-circuit breathing are design records only. The
visual-test Engineer armor still has iron statistics. Rejected project17 skins
and CPM compatibility are historical archive material and must not be installed.
