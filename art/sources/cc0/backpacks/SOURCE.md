# Backpack icon sources

Original author: twiswist. [Inventory filter icons](https://opengameart.org/content/inventory-filter-icons), declared CC0-1.0. The primary page describes 16×16 replacement inventory icons for Crossfire, using an Arne16-based palette.

Downloaded on 2026-10-08 from the [primary archive](https://opengameart.org/sites/default/files/inventory_icons.zip). `sources.json` records the original whole members, byte hashes, archive hash, page snapshot hash and license copy hash. The downloaded archive includes separate `bag.png` and `sack.png`; neither is cropped from the optional sheet.

`bag.png` supplies both backpack item icons. `sack.png` supplies the bundled woven-fabric component icon. Only bijective color substitutions are applied by `tools/GenerateBackpackPalettes.java`; dimensions, pixel classes, alpha and silhouette remain unchanged. No bitmap is drawn, resized, rotated, mirrored or composited.

The original source images were compared to 1568 complete 16×16 block/item images in the installed Minecraft1.21.1 resources, including whole flips/rotations and palette-class/alpha comparisons. No matches were found. This is a bounded technical comparison, not a blanket rights certification. The primary source declaration is retained.
