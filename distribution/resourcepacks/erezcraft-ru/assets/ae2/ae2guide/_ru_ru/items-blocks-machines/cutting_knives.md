# Кварцевые инструменты

<Row>

  <ItemImage id="nether_quartz_cutting_knife" scale="4" />

Режущие ножи используются для создания <ItemLink id="name_press" /> и <ItemLink id="cable_anchor" />.

Чтобы создать именующий пресс, щёлкните правой кнопкой мыши по режущему ножу и вставьте слиток металла, затем вам нужно будет ввести имя, которое вы хотите написать на пластине, и просто извлечь готовую пластину.
