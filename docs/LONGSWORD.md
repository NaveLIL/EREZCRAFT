# Два меча из рифтстали

Локальная доработка по поручению владельца 27.10.2026. Оригинальный меч сохранён, удлинённая модель LS-03 стала **отдельным предметом**, а не заменой.

| Свойство | Обычный меч | Длинный меч |
|---|---|---|
| ID | `interstice:riftsteel_sword` | `interstice:riftsteel_longsword` |
| Урон полностью заряженного обычного удара без брони/эффектов | 7 | 11 |
| Скорость атаки | 1,6 | 1,6 |
| Прочность | 1792 | 1792 |
| Крафт | 2 слитка рифтстали + местная палка | 4 слитка рифтстали + местная палка |
| Ремонт | Рифтсталь | Рифтсталь |

Дальность взаимодействия не меняется. Разница +4 урона выбрана владельцем. Самостоятельный Survival-баланс не подтверждён.

Рецепт длинного меча, где М — слиток рифтстали, П — местная палка:

```text
 М
МММ
 П
```

Оба меча доступны в родной творческой вкладке. Новый рецепт открывается при получении рифтстали. Классификация `minecraft:swords`, общие теги инструментов, семейства зачарований меча/оружия/прочности и ремонт включают новый предмет. Старые ID, модель, рецепт и параметры не меняются.

Команды для отдельного тестового мира:

```mcfunction
/give @s interstice:riftsteel_sword
/give @s interstice:riftsteel_longsword
```

## Геометрия и воспроизведение

Авторский проект: `D:/repos/Blender/creations/12_minecraft_longsword/`. Генератор `tools/build_refined.py`, конфигурация `source/design.json`, Blender-сцены и превью находятся вместе. Результат развёрнут в `assets/interstice/models/item/riftsteel_longsword.json`. Прежний `riftsteel_sword.json` сохранён побайтно.

Источник текстуры — Malcolm Riley / unused-textures, CC BY 4.0; исходный PNG не изменён. Атрибуция: `assets/interstice/provenance/armaments.json` и `riftsteel-longsword.json`. В новой геометрии сохранён размер исходного пикселя 0,5 модельной единицы, рукоять и гарда; клинок длиннее и имеет выровненное остриё.

Модель использует корень `minecraft:block/block` с явно заданными ванильными положениями предмета в руках. Наследование от `item/generated` здесь не подходит: Minecraft заменяет явные элементы автоматически сгенерированной геометрией спрайта. Нативная проверка требует именно 704 грани новой модели и выхода острия за исходный квадрат 16×16 модельных единиц.
