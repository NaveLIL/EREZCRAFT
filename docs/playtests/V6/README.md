# Слепой Survival-тест V6

Это воспроизводимый пакет для независимого человеческого теста по [§20 запроса V6](../../V6_REQUEST.txt). **Тестирование людьми не проведено; журналы пусты.** Подготовленный автоматический сценарий прогрессии проверил механизмы на заранее выданных материалах и не заменяет этот тест.

Пакет предназначен для окончательного кандидата с естественным первым входом в `interstice:islands_v6`, генератором ревизии 6. Опубликованный baseline **0.7.0-preview.1** пока ведёт при обычном входе в V5 и **не проходит этот допуск**. Его Creative-обзор V6 через команду полезен для визуального осмотра, но не считается Survival-маршрутом. Работающий профиль владельца не используется.

Модератор читает [MODERATOR.md](MODERATOR.md), фиксирует точный кандидат и проводит допуск по [manifest.json](manifest.json) и [preflight.json](preflight.json). Игроку передаётся **только [TESTER.md](TESTER.md)** и готовый пустой игровой профиль. Не передавайте ему манифест seed, список этапов, README проекта или внешние рецепты.

| Файл | Назначение |
|---|---|
| `manifest.json` | Версии, baseline SHA256, неизменяемые шесть seed, настройки и критерии допуска |
| `preflight.json` | Пустая запись фактической проверки кандидата до приглашения тестера |
| `sessions.csv` | Назначение игроков, условия, итог и причины остановки по каждому seed |
| `timings.csv` | Пустые строки одиннадцати этапов для каждого seed |
| `events.csv` | Паузы, ожидание, попытки и операции с причинами и временем |
| `deaths_losses.csv` | Смерти, восстановленный груз и подтверждённые потери |
| `external_hints.csv` | Каждый запрос и каждая внешняя подсказка |

CSV используют UTF-8, запятую и стандартное экранирование кавычками. Пустое значение означает «не измерено», а не ноль. Оригинальные шаблоны сохраняются; результаты записывают в копии внутри нового отдельного профиля или папки отчёта. Итог привязывают к SHA256 реально запущенного JAR и исходным журналам.

Пакет не закрывает dedicated-приёмку двух настоящих клиентов, нагрузку или естественное заселение нового вида. Эти результаты ведутся отдельно. Экспериментальный Эхо-разлом preview не имеет естественного размещения/Survival-рецепта; его вручную созданная сущность существует без заданного срока жизни. Он не выдаётся тестеру и не служит обходом естественного маршрута.
