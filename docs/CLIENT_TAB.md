# Компактный Tab EREZCRAFT

Клиентский кандидат **erezcraft-client-ui 0.1.0**, 21.10.2026. Дизайн выбран
владельцем: «Атмосфера Междуморья», компактно, без строки «МЕХАНИЗМЫ · МАГИЯ ·
ПОЛЁТ» и без ролей. Владелец утвердил окончательный игровой вид. Опубликована **alpha.16 / sequence16**,
65 клиентских JAR / 75 файлов; лаунчер **0.4.6** прежний.

Вверху — EREZCRAFT и настоящее число игроков. Общий алфавитный список содержит
голову скина, игровой ник и измеренный Minecraft пинг. Режим наблюдателя сортируется
после остальных игроков. Своя строка слегка выделяется; это не ранг. Нет выдуманных
ролей, AFK, TPS или данных о местонахождении игроков.

До пяти игроков используется одна колонка шириной 224 GUI-пикселя; при большем
списке и достаточной ширине — две колонки общей шириной 344 GUI-пикселя. Высота
зависит от числа строк и доступного экрана. Длинные имена сокращаются, пинг
остаётся видимым. При переполнении внизу появляется диапазон и подсказка «Колесо»:
удерживая Tab, можно прокручивать страницы. Отпускание Tab возвращает первую
страницу. Колесо не перехватывается при закрытом Tab, открытом экране, скрытом HUD,
отключённом оформлении или активном scoreboard objective.

Головы рисуются штатным `PlayerFaceRenderer` через `PlayerInfo.getSkin()`, включая
слой шапки и обычные настройки модели. Используются существующие проверка
подписи, загрузка и кеш скинов Minecraft/authlib-injector. Новых запросов к
аккаунтам, сетевых payload, токенов, обхода подписей или смены UUID нет. Без
пользовательского скина Minecraft показывает обычную стандартную голову.

Модуль отключается через **Моды → EREZCRAFT: Client UI → Настройки**. Файл:
`config/erezcraft_ui-client.toml`, параметр `compactPlayerList`. Если сервер
использует очки/здоровье в player-list objective, весь Tab автоматически рисует
Minecraft: игровая информация scoreboard не теряется.

## Артефакт и границы

Сборка отдельной задачей `clientUiJar`; она также включена в `assemble`.
Артефакт: `build/libs/erezcraft-client-ui-0.1.0.jar`. В нём только три класса UI,
два языка, client-only mixin и метаданные/лицензия. В серверный `interstice` JAR
он не включён. Для будущего обновления лаунчера нужно добавить **один** клиентский
JAR в новый подписанный manifest с sequence **выше фактического публичного**.
Старый immutable release не заменять. Перед публикацией заново проверить канал.

Игровой сервер не требует этого модуля. Его установка/перезапуск, новая версия
Interstice, изменение EREZ ID или миграция мира для Tab не нужны. На других
лаунчерах файл может быть установлен вручную, но он не даёт обхода EREZ ID.

Все 74 файла alpha.15 при подготовке native-профиля скопированы по прежнему
подписанному manifest; добавлен UI JAR. Исходный `interstice-0.7.0-preview.12.jar`
совпадает с публичным по SHA256. Океаны, настоящая V6, фауна, руды, поверхности,
157 PNG, шейдеры и настройки пользователей не изменены.

## Проверка

`tools/client-ui-smoke/prepare.py` создаёт исключительно новый каталог
`D:/repos/erezcraft/.local/verification/tab-ui-*`. Взяты 64 настоящих клиентских
JAR alpha.15, добавлен UI и временный диагностический JAR. Миры/аккаунты владельца
не копируются. Профиль запускает настоящий клиент через проверку подписанного
manifest и `game::prepare_local` / `game::spawn` из примера
`D:/repos/erezcraft/crates/launcher-core/examples/client_ui_smoke.rs`.

Диагностика создаёт новый плоский **minecraft:overworld**, передаёт искусственные
player-list пакеты локальному клиенту и удерживает штатную клавишу Tab. Это
проверка интерфейса, не реальный онлайн 80 игроков, не вход в V5/V6 и не нагрузочный
тест сервера. Обязательный DH загружается; его генерация только в этой фикстуре
выключена. Для проверки скина используется публичный подписанный профиль EREZ ID,
без OAuth/игровой сессии. Штатный `SkinManager` должен подтвердить `secure=true`.

Сохраняются кадры для 4/10 игроков, 80 записей на малом экране, второй страницы,
отключённого оформления и scoreboard fallback. Проверяются фабрика настоящего
экрана настроек, поглощение события колеса при переполнении и штатная остановка
собственного integrated server. Промежуточный прогон `tab-ui-20261021-b` прошёл
до добавления прокрутки; окончательный артефакт и результаты фиксируются отдельно
в [docs/verification/CLIENT_TAB.json](verification/CLIENT_TAB.json).

Окончательный прогон **tab-ui-20261021-c** прошёл, процесс завершился с кодом 0.
Все шесть native-кадров просмотрены по сохранённым путям в отчёте;
четыре и десять строк действительно заменяют обычный Tab, а на второй странице
малого экрана видны другие игроки, диапазон **13–24 / 80**. Два fallback-кадра
сохранены отдельно. Настоящая фабрика экрана настроек зарегистрирована, EREZ ID
скин имеет `secure=true`, собственный integrated server штатно остановлен.

SHA256 окончательного JAR: `2ee43080502dca39d03a58fb4c4f7c93ace28487ef28cac05f449b1f6c8239aa`,
**14 392 байта**. Он опубликован после визуального утверждения. Полный
server/gameplay/security аудит, повтор всех worldgen GameTests и 80 реальных
клиентов в этой интерфейсной задаче не проводились и не заявляются.
