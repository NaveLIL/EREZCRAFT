# Служебный воздух Distant Horizons

В полном свежем клиенте11.10.2026 выявлена ошибка прежней поправки слабого
свечения: `DhV6MaterialMixin` обращался к `blockState.getBlock()` у служебного
`BlockStateWrapper_neoforge.AIR`. В DH3.3.3 эта запись намеренно имеет
`blockState=null`; она создаётся в статическом инициализаторе, а её исходный
`getMaterialId()` возвращает сохранённый байт материала AIR.

Исправление — ранний выход `if (blockState == null) return;` до обращения
к Minecraft, миру или callback. Штатный метод DH выполняется дальше.
Материал не подменяется числом0: его реальное значение для этой закреплённой
версии —14. Правила слабого свечения для настоящих блоков сохранены.
Палитра, световая карта, shader bridge, остальные mixins, поверхности и
геометрия океанов не менялись.

Компонентная проверка читает настоящий compiled control flow и подтверждает
немедленный RETURN для null до доступа к клиенту/callback. Сам DH исключён
из искусственного NeoForge GameTestServer по известному контракту этого
стенда; это не проверка настоящего рендера.

Отдельная полная клиентская проверка в настоящей `interstice:islands_v6`
вызывает реальный DH AIR1024 раза на render thread и1024 раза на worker.
Проверяются тождество записей null/ванильного воздуха и сохранение исходного
материала. В исправленном клиентском прогоне ошибки null отсутствуют.
Сырые итоги и SHA кандидата: [REALM_EXPANSION.json](verification/REALM_EXPANSION.json).

Пользовательские кеши DH и миры для исправления не удаляются. Другие
измерения также получают безопасный штатный результат для служебного AIR;
поправка цвета по-прежнему ограничена V6.
