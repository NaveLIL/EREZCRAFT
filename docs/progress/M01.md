## Реализованная проверка

`src/infection/` — отдельный source set и тестовый мод `interstice_probe`.
Spore включён только в его compile/runtime classpath. Обычные профили загружают
только Interstice; профиль `infectionGameTestServer` явно добавляет probe.
Релизный JAR не содержит probe, Spore, smoke-классов, сохранений или исследования.
Его SHA-256 после проверки совпадает с M00:
`9a6a0c7427f8bc592b9ee9605efb116252594c347002dacbe8708a906fb46baf`.

Каждый запуск создаёт новый профиль. Тестовый мир использует собственные
измерение и биом `interstice_probe:basin`, seed 0, плоский грунт с травой Y=64.
Один оригинальный `spore:mound` размещается около (8.5,65,8.5). Его рост
вызывается собственным игровым таймером: прямого вызова распространения,
ускорения возраста или изменения конфигурации нет. Проверяются штатные
`mound_cooldown=30`, `mound_age=900`, жизнь сущности, сброс родного таймера
и фактическое изменение грунта. 3×3 тестовых чанка удерживаются на время
наблюдения и освобождаются при успешном завершении.

Свежий финальный результат: **0 → 2 блока Spore, 0 → 9 блоков vanilla
mycelium за 646 серверных тиков**, наблюдался один сброс таймера; возраст 1.
Мицелий учитывается отдельно, поскольку исходный мод переводит траву именно
в `minecraft:mycelium`. Тест требует ненулевые блоки Spore и суммарно не менее
8 изменённых блоков, но не требует двух циклов. В предыдущем успешном
наблюдении было два цикла и итог 2+20 блоков. Точное число преобразований
случайно даже при фиксированном seed; ускоренные GameTest-тики не равны
такому же числу реальных секунд.

## Ошибки и их классификация

Сохранены неудачные проверки; их результаты не переписаны успешным запуском:

* `.verification/20261006T172604.850896Z-M01-native/`: измерение basin не
  загружалось. Ошибка стенда: GameTestServer использует world preset `minecraft:flat`.
  Исправлен только preset тестового source set с добавлением basin и сохранением
  трёх vanilla-измерений.
* `.verification/20261006T173213.319783Z-M01-preset/`: счётчик учитывал только
  namespace Spore и пропускал vanilla mycelium. Исправлена методика измерения,
  а не рост стороннего мода. Следующий исходный успешный рост сохранён в
  `.verification/20261006T173424.309345Z-M01-native-growth/`.

Исходный Spore сообщает ошибки необязательных рецептов Farmer's Delight/Create
при отсутствии этих модов; запуск и рост продолжаются. Это замечания к данным
необязательных интеграций закреплённого кандидата, а не причина установки
дополнительных крупных модов. Сообщение об отсутствующем server.properties
в новом профиле также не завершало процесс аварийно.

Runner теперь отвергает нулевой код без завершившихся GameTests, отсутствующий
или отрицательный JSON smoke и ошибку запуска процесса. Эти случаи проверены
отдельно. Старый `runClientSmoke` пока не включён в runner: ему сначала нужен
структурированный результат, прежде чем использовать его для приёмки M03.
