# V6: промежуточная сборка для проверки

Версия: **0.7.0-preview.1**, Minecraft **1.21.1**, NeoForge **21.1.252**, Java **21**.
Это промежуточная сборка: разработка и полная приёмка V6 продолжаются.

Готовый JAR и SHA256 доступны в [preview-релизе](https://github.com/NaveLIL/EREZCRAFT/releases/tag/v0.7.0-preview.1).
Проверено **418 GameTests в 15 группах**, 63 проверки Python и два отдельных
клиентских запуска прогрессии. [Точный отчёт](verification/V6_PREVIEW.json)
содержит хеши JAR, источников и незакрытую приёмку.

## Запуск на другом ПК

Ветка `main` содержит объединённые улучшения рюкзаков, пещерных разломных пауков
и текущую разработку V6. Установите NeoForge указанной версии. Из успешного
GitHub Actions запуска скачайте архив `verification-windows-latest` или
`verification-ubuntu-latest`; поместите **interstice-0.7.0-preview.1.jar** в `mods`
клиента и сервера. `sources.jar` предназначен для разработчиков.

При запуске из исходников нужен JDK 21: `./gradlew runClient`, на Windows
`.\gradlew.bat runClient`. Папки сборки, локальные исследования и игровые
сохранения не распространяются через Git.

Для визуальной проверки создайте отдельный мир с разрешёнными командами:

```mcfunction
/interstice explore v6
```

V6 — отдельное измерение `interstice:islands_v6`. По умолчанию входы пока ведут
в принятую V5: окончательное переключение произойдёт после проверки генерации.
Существующие порталы сохраняют своё измерение. Команда `/interstice leave`
возвращает в обычный мир; `/interstice tide set surge` и `calm` позволяют
проверить прилив и спокойную фазу. Обычное исследование и подготовленная
Creative-проверка имеют разный смысл.

## Что включено

- Четыре пространственные роли: рассечённые парящие пласты, минеральные чаши,
  каменные своды и низкие корневые прорези. Пещеры компактные, входы дорабатываются.
- Палитра «Минеральная ночь»: рисунки и прозрачность принятых текстур сохранены.
  Цвета морей и их анимации не менялись. Общие материалы меняют внешний вид и
  старых миров, их блоки не заменяются.
- Исправленные открытия портальных рецептов и мокрые твёрдые крыши;
  непрерывная приливная сила, ремонт пояса, каталитическое изготовление мембран
  после первой находки, общий именованный маяк, 27 грузовых слотов лифта,
  управляемый спуск с лебёдкой и искатель редких построек.
- Обновлённые автором рюкзаки и модули. Клавиша **B** открывает сумку,
  **Shift+ПКМ** меняет ношение на спине. Правила модулей — в [BACKPACKS.md](BACKPACKS.md).
- Три авторских подвида пещерных разломных пауков, паутина и кладки;
  обитатель венечных крон. Новое естественное заселение проверяется в V6.
- Авторский Эхо-разлом из дополнительной ветки: петля движения, отражение
  снарядов и собираемые осколки. Пока это экспериментальный объект для ручной
  проверки: `/give @s interstice:echo_rift_anchor`. Его естественное размещение
  и Survival-рецепт ещё не включены. Текущие разломы постоянны и восстанавливают
  запас осколков; ограничение срока жизни не вводилось без отдельного решения.

## Незакрытая приёмка

Первый полный прогон шести seed сохранил отрицательные результаты доступности
пещер и начальных культур; они не скрываются подбором другого seed. Доработки
входов и береговых колоний требуют повторной проверки. Сеть, холодный перезапуск,
нагрузка и самостоятельное прохождение Survival проверяются отдельно.
Независимая человеческая приёмка ещё не проведена.

Текущее состояние и конкретные результаты: [журнал V6](progress/V6_AUTONOMOUS_WORK.md),
[художественная система](V6_ART_DESIGN.md), [сетевая проверка](V6_NETWORK_PROBE.md).
