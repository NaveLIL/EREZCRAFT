# Приливные фантомы V6

`interstice:tide_phantom` действует только в настоящем `interstice:islands_v6`
с генератором revision6. Обычный ванильный фантом и правила других измерений
не меняются. Используется ванильная модель; новых текстур нет.

Фантомы появляются в фазе WARNING, кружат около игроков и начинают охоту
только в SURGE. CALM и EBB удаляют их. Спавнер проверяет сложность,
`doMobSpawning`, серверный запрет монстров, общий бюджет враждебных мобов,
границу мира, дистанцию до игроков и уже загруженные чанки. Лимиты:2 рядом
с игроком,8 на измерение; не больше6 кандидатов раз в80 тиков.

Захват требует живого игрока Survival, расстояния до2.4 блока, прямой
видимости и доступного выхода из укрытия. Проверка ищет путь шириной с игрока
к открытому столбу в радиусе до12 блоков. Стены, частичные коллизии, жидкости
и незагруженные чанки запрещают путь. Закрытая комната и достаточно широкая
крыша сохраняют защиту.

Во время захвата фантом прикладывает обычную горизонтальную скорость
с пределом0.22 блока/тик, сохраняя вертикальную скорость. Игрок не становится
пассажиром, не телепортируется и не получает разрешение на полёт. За пределами
крыши фантом отпускает его; дальше действует принятая механика прилива.
Удар по фантому также освобождает игрока. Захват прекращается при препятствии,
смерти, выходе, смене измерения/режима/фазы или через60 тиков; повторная атака
имеет паузу80 тиков. Один игрок может удерживаться только одним фантомом.
Связь захвата не сохраняется в NBT.

Компонентные проверки: `runRealmExpansionGameTestServer`, namespace
`interstice_tide_fauna`. Они используют отдельные подготовленные сцены V6
и восстанавливают календарь через NBT. Проверка полной сборки находится
в `D:\repos\erezcraft\tools\realm-expansion-smoke`; она отдельно фиксирует
реальные тики, пакеты скорости, освобождение и остановку интегрированного
сервера. Результаты публикуются только после выполнения.

Визуальное поведение, полный естественный цикл прилива в Survival,
выходы из сложных пользовательских построек и multiplayer anti-flight
остаются отдельными проверками. Компонентный тест их не заменяет.
