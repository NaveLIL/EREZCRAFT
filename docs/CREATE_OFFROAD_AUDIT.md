`Create Offroad 1.3.2` вложен в `create-aeronautics-bundled-1.21.1-1.3.2.jar`.
Это отдельный загружаемый модуль `offroad`, а не Flywheel и не только декоративные колёса.

## Что реализовано в установленной версии

| Возможность | Подтверждение |
|---|---|
| Колёсное крепление | `offroad:wheel_mount`, класс `WheelMountBlockEntity` |
| Привод от Create | Наследует `KineticBlockEntity`, использует `getSpeed()` в расчёте физики |
| Контакт с грунтом | `computeMaxExtensionToTerrain()`, вычисление трения поверхности |
| Воздействие на машину | `sable$physicsTick()`, `ForceTotal.applyImpulseAtPoint()`, `RigidBodyHandle.applyForcesAndReset()` |
| Подвеска | Ход `extension`, настраиваемая `SuspensionStrengthValueBehaviour`, настройка прочности/жёсткости в интерфейсе |
| Руление | Разность сигналов редстоуна с двух сторон, пропорциональный угол до ±30° |
| Торможение | Верхний сигнал редстоуна; штатная подсказка описывает повышение трения колеса |
| Несколько шин | `small_tire`, `tire`, `large_tire`, `monstrous_tire`; предметы и рецепты присутствуют |

В `TireLike` хранятся радиус, положение/поворот визуальной модели, необязательная
ссылка на модель и минимальное трение. Штатные радиусы шин: 0,75; 0,96875;
1,25; 2 блока, то есть диаметры 1,5; 1,9375; 2,5; 4 блока.
`offset` не следует считать подтверждённым способом произвольно смещать физическую
точку контакта: в просмотренном физическом коде точка крепления привязана к блокам.

## Что это означает для Eitan

Физику колёс с нуля писать не требуется: можно опираться на Offroad + Create + Sable.
Для восьмиколёсной машины ещё нужны проверка расположения креплений, подбор
диаметра шин, передача вращения, связь органов управления с рулением/тормозом,
настройка подвески под игровую массу и коллизии корпуса.
Точный масштаб реальной машины может потребовать собственного варианта шины
или адаптации креплений: готовые размеры и блочная сетка не подтверждают
автоматического совпадения со всеми расстояниями настоящего Eitan.

**Граница проверки:** наличие механики, код и загрузка модуля подтверждены.
Заезд колёсного шасси, восьмиколёсная компоновка, проходимость и серверное
управление несколькими игроками здесь не проверялись. Новые игровые клиенты
не запускались; сервер, модпак, настройки и пользовательские миры не менялись.
