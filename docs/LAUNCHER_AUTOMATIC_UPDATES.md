# Автоматическое обновление Windows-лаунчера — 21.10.2026

Опубликован **0.4.5 / updater sequence6** на https://launcher.erezcraft.com.
SHA256 EXE: `145f5e2c3f36cd31ffe0055b43bf44a97e7a61e33002875a1ae24e0011bce4cf`.
Размер24238080байт. Канал подписан прежним Ed25519 ключом; подпись, публичное
HTTPS-скачивание и ссылка страницы проверены. Предыдущие EXE неизменны.

Лаунчер сам проверяет канал при открытии и каждые10минут простоя. Доступную
версию скачивает, показывает прогресс и перезапускается. Во время Minecraft,
установки сборки и входа через Discord обновление ждёт. Слушатели подключаются
до первой проверки; прогресс виден и на странице аккаунта. Нажатие «Играть»
во время начальной проверки или установки не запускает параллельную операцию.
Ошибки показаны с повторной попыткой; недоступный updater не лишает рабочую
установку возможности запуска. Стрелка ↗ с кнопки «Играть» убрана.

После неудачного старта новой версии helper по-прежнему восстанавливает старую.
Теперь receipt отката сохраняется после bootstrap и следующих открытий;
автоматическая установка приостановлена до явного нажатия кнопки. Это
предотвращает цикл «загрузка → неудачный старт → откат → загрузка». Запуск
установленной игры разрешён. Подпись, полный хеш, запрет отката версии/sequence,
ограничение путей и нативное подтверждение нового WebView сохранены.

## Переход со старой версии

В0.4.1–0.4.3 установка ещё требует однократного нажатия «Обновить и перезапустить».
Открытое старое окно можно закрыть и открыть для свежего предложения версии.
Если кнопка не реагирует, скачать новый EXE с сайта и заменить прежний в той же
папке при закрытом лаунчере. Portable-данные должны остаться рядом с ним.
Начиная с0.4.4 следующие обновления устанавливаются автоматически.
В0.3.x ещё нет протокола подписанных обновлений — требуется ручной переход.
Это Windows portable x64; публичный macOS updater в этот выпуск не входит.
