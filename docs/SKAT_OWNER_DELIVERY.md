# Один Скат для владельца — 29.10.2026

По прямому поручению владельца удалены все три ранее созданных им Ската в production V6. Два корпуса практически совпадали у (57, 37–38, 104). Перед удалением зафиксированы зависания `Rapier3D.step`, сработал ServerHangWatchdog; конкретная причина внутри native Rapier не доказана. Пересечение корпусов — вероятный триггер.

При диагностике один раз ошибочно вызвана голая `sable paused`: она переключает паузу, а не читает состояние. Дальнейшие операции используют только явные true/false. Очистка выполнена штатным `sable remove` по имени с точным количеством; временная копия также удалена.

Вместо повреждённого старого экземпляра из канонической SK03 подготовлена маленькая административная Sable-схема с 1509 клетками. Она размещена по текущим X/Z владельца: (6.954, 38, 91.652). Оба двигателя получили по 64000 тиков топлива, все три световые линии включены. Настоящая проверка обнаружила оба винта, по 63855 оставшихся тиков в двигателях и Lighting=7. Физика включена.

После `save-all flush` подтверждены ровно один активный и один сохранённый Скат. Временные terrain-forceload билеты сняты; ландшафт не заменялся, резервных архивов не создавалось. Проверка сервера: 20 TPS, средний тик 12.9 мс, P95 18.0 / P99 21.6 мс. Эти замеры не доказывают клиентский FPS или нагрузочную ёмкость.

Открытый дефект: preflight чертежа проверяет обычные блоки, но не пересечение с уже существующим телом Sable. Нужны защита размещения и отдельная проверка нескольких корпусов; удаление дублей не считается исправлением native Rapier. Административная схема не меняет опубликованный клиент alpha.23, рецепты или прогрессию.

Владелец затем сообщил: «тебе пожаловался и он поплыл». Настройки тяги и сервер в ответ не менялись. В следующих трёх снимках двигатели уже были в нейтрали (0 RPM), оба запаса топлива — 62462 тика, корпус сменил мировую позицию относительно выдачи. Сервер healthy / 20 TPS, средний тик 9.4 мс. Причина первой задержки старта не установлена; это не измерение скорости под непрерывной тягой и не приёмка рейса двух игроков.
