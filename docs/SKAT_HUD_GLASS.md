# Спидометр Ската и море за стеклом

29.10.2026. Подготовлен Interstice **0.7.0-preview.100-skat-speed**, SHA-256 `3ff24eec51cb3f427195ed164d5ab347be7ba1267f46eba5467be14aee37cd06`. **Alpha.24 / sequence24 опубликована**, сервер обновлён и healthy. HTTPS/Ed25519/SHA-256 подтверждены; клиент 79 JAR/89 файлов, 87 прежних записей/URL/политик сохранены. Сервер 67 JAR, остальные 66 побайтно прежние.

Панель пилота показывает горизонтальную скорость в м/с и км/ч вместе с топливом. Сервер измеряет смещение фиксированной точки корпуса за игровые тики; вертикальная качка не учитывается. Первое измерение, смена корпуса, пауза измерения, телепортация и некорректные числа сбрасывают показание. Значение сглаживается и приходит дважды в секунду только фактическому пилоту. При отсутствии поддержки/свежих данных показывается тире. Обороты винтов не подменяют скорость.

Добавлен отдельный необязательный канал `skat-speed-v1`; прежние четыре payload, их codec и байткод не изменены. Сервер отправляет новый пакет только соединению, которое объявило его поддержку.

Ближняя непрозрачная поверхность токсина теперь рисуется после cutout-блоков, перед прозрачными материалами. Прежний поздний проход оставлял глубину стекла перед морем и отбрасывал его фрагменты. Маска сухого корпуса, волны и DH сохранены. Переключатель прежнего порядка предназначен только для изолированного A/B теста; в обычной игре выключен.

Проверены восемь контрактов спидометра; настоящий клиент Sodium/Sable/DH, настоящая V6, реальный ход/поворот и HUD. Короткие прогоны дают разные скорости разгона; они не являются замером установившейся крейсерской скорости. Коэффициент тяги не менялся.

Три вида из рубки проверены на одной зафиксированной позе до/после изменения порядка проходов. В двух видах восстановлено ранее отсутствовавшее ближнее море; третий сохранил видимость. Диагностические A/B кадры используют ночное зрение, заключительный обычный кадр — без него и без HUD, со светом 7. Шейдеры выключены по последнему уточнению владельца; Complementary в этом исправлении не проверялся. Сохранены 1509 клеток, 24 контейнера, все 3128 прежних asset/data entries кроме добавления четырёх подписей HUD в каждом языке.

Расширенный прогон также один раз застрял на подъёме по прежней лестнице: исходная геометрия и её код не менялись, результат сохранён в `.verification/skat-20261029/speed100_01_full-probe.json`.
