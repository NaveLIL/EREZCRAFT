## Факты и границы проверок

- 12 оригинальных JAR скачаны из Modrinth и проверены по SHA-512. Полная сборка:
  **79 клиентских JAR**; все 67 прежних сохранены. В подписанном пакете 89 файлов.
- Итоговый настоящий клиент с DH достиг меню и штатно закрылся: 107 mod IDs,
  все версии совпали; проверены **18 974 уникальные строки** и **430 ресурсов книг**.
  Все исходные миры и настройки владельца вне проверки. Первый запуск был
  отрицательным из-за неверного ожидания версии Patchouli (`${file.jarVersion}`),
  следующий выявил 30 конфликтующих общих подписей между namespaces. Ожидание
  исправлено, общие переводы согласованы; итоговые проверки прошли.
- Имена трёх новых JAR нормализованы для строгих правил доставки (пробелы, скобки
  и `+` заменены дефисами); байты и оригинальные CDN URL сохранены. Первые две
  подготовки доставки отклонены издателем из-за имён, до смены публичного канала.
  Финальный набор имён отдельно проверен настоящим клиентом.
- Отдельный dedicated server с 67 обычными JAR и диагностическим модом запущен
  на домашнем узле. Docker публикует только `127.0.0.1:25567`; мир игроков,
  авторизация и производственные порты не используются. Все девять выбранных
  модов зарегистрировали реальные рецепты. Slice & Dice потребовал уже имеющийся
  клиентский KotlinForForge 5.12.0 и на сервере; зависимость добавлена в кандидата.
- В одноразовом мире поезд собран из станции/тележки/пульта, проехал 20 блоков
  без схода и сохранился после настоящего перезапуска JVM с прежним UUID и позицией.
  Управление синтетическое: это не проверка нажатий игрока, расписаний, всех
  типов путей или баланса Survival. Первая попытка выявила ошибку тестовой
  конструкции: пульт смотрел против направления сборки (`no_controls`).
  Исправлено направление пульта; код Create/Steam 'n' Rails не менялся.
  Receipts: `.verification/mod-candidates-20261024/industry-train-validation.json`
  и `industry-train-cold.json`, оба `passed:true`. Контейнер после проверки остановлен.
- Автокрафт термоядерного синтеза и сохранность остальных работающих машин
  ещё не проверены. Успешный старт этого не доказывает.
- Незавершённые исправления фауны preview.14 **не включены** в этот кандидат.
  Исходный Interstice здесь — опубликованный preview.13.

## Переводы

Проверяются отсутствующие ключи **и английские значения внутри ru_ru.json**.
В CEI/Dragons Plus/PackagedAuto нашлись сотни таких значений. Подготовлены собственные
переводы новых интерфейсов/Ponder и книги PackagedAuto/PackagedDraconic.

RTF 2.8.4 содержит 233 файла книги PneumaticCraft, но большинство текстов английские.
Использованы только действительно русские фрагменты с точно совпадающим английским
источником. Источник и хеши сохранены в `SOURCES-INDUSTRY.json`; исторический
[LICENSE RTF](https://github.com/Russian-Translations-and-Fixes/RTF/blob/326542ab6552a016681527637fddf8e4d0b7f1d5/LICENSE)
включён в пакет. Общая лицензия ресурс-пака — AGPL-3.0-only.

Черновики из публичного английского руководства получены с помощью Google;
данные игроков, приватный код и учётные данные не отправлялись. Выполнена ручная
смысловая переработка: 999 фрагментов черновика, 17 неудавшихся фрагментов и
дополнительные страницы текущей версии. Заголовки рецептов используют русские
имена предметов из точной версии мода, функции API и идентификаторы сохранены.
Ошибки вроде `sneak` → «скрытность», `tank` → «танк», утраты `${...}` и перевода
завершения операции как запуска исправлены. Исходные машинные черновики не публикуются.

Добавлено 259 Patchouli-ресурсов и 9 страниц GuideME; с прежними книгами всего
288 Patchouli-ресурсов и 142 страницы Markdown. Проверены ссылки, параметры,
форматирование и технические поля. Установленный парсер GuideME разобрал все
142 страницы; Java проверила все 503 записи ZIP. Непереведённых фрагментов — 0.
Это не визуальная проверка вёрстки каждой страницы.

Одна предварительная статическая проверка дала ноль отсутствующих языковых ключей,
но не прошла из-за ссылки RTF `condition_item_filter` вместо `condition_item`.
Кроме того, английские заглушки книги выявлены отдельной смысловой проверкой;
этот ранний отчёт **не закрывает русификацию**.

## Воспроизводимая сборка и доставка

`node tools/localization/build-industry.mjs` собирает принятый ресурс-пак из
версионированных исходников без локальных кешей и сверяет SHA-256 с `acceptance.json`.
Артефакт: `build/distributions/erezcraft-industry-ru-mc1.21.1.zip`, 878840 байт,
SHA-256 `d60538ba17a995e191183513d9f833f79d97801258ac60e2a36f600ad6cb328a`.

`industry-build.py` по умолчанию останавливает выпуск при непереведённых фрагментах;
`--allow-incomplete` предназначен только для изолированных черновых проверок.
Издатель проверяет подписи, исходный sequence17 и точные хеши, сохраняет все
75 незатронутых записей манифеста и меняет только 12 новых JAR, RU ZIP и маркер.
Конфигурации игроков сохраняют прежнюю seed/managed policy.

Настоящий `Installer::synchronize` получил обновление **17 → 18 по HTTPS**:
89 проверенных файлов, 14 новых/заменённых, 0 удалённых. Повреждённый RU ZIP
с прежними размером и mtime восстановлен повторным скачиванием; следующий проход
дал 89/0. Тестовые world/options и личная настройка интерфейса сохранены.
Пользовательские профили в этих проверках не использовались.

На сервер добавлены только 13 JAR (12 новых зависимостей/модов и KotlinForForge);
54 прежних JAR побайтно сохранены. Сервер здоров, OP4 только владельца,
online EREZ ID и параметры compose сохранены. Настоящий RSA/AES вход без сессии
отклонён именно авторизацией до модового handshake. Старые Tst-данные не получили сессию ещё до игрового соединения; менять аккаунт
или обходить допуск ради проверки не стали. Полный положительный вход игрока
с обновлённой сборкой ещё не подтверждён; это не проверка нагрузки десяти игроков.
Копия остановленного мира проверена по 707 файлам, затем мир и серверные настройки
зашифрованы и переданы в `D:\EREZCRAFT\backups`; VPS резервные архивы не получает.

Проверка: [INDUSTRY_EXPANSION.json](verification/INDUSTRY_EXPANSION.json).
