# Готовые инструменты генерации и построек

В M14 уже использована часть готового подхода: упаковка и ветвление JoCode адаптированы из Dynamic Trees с сохранением MIT лицензии; runtime мод не устанавливался. Собственные пути задают кольца, переплетения и подвесные грозди. [Настройка](PALE_GARDENS.md), [закреплённый источник](third-party/dynamic-trees-jocode.json).

Проверено **08.10.2026** для Minecraft **1.21.1**, NeoForge **21.1.252**, Java **21**. Это исследование и предложение интеграции: зависимости и пользовательские миры не изменены. Поддержка версии подтверждена исходниками и опубликованными метаданными; совместимость с Междуморьем ещё требует отдельного испытания.

## Что использовать первым

Для небольших руин достаточно уже имеющегося `StructureTemplate`. Для лабораторий и обсерватории следует сначала попробовать встроенный **Jigsaw**: собственные комнаты в NBT, соединители, взвешенные `template_pool`, процессоры повреждений и ограниченная глубина сборки. Эти классы присутствуют в текущей зависимости Minecraft 1.21.1: `JigsawPlacement`, `JigsawStructure`, `StructureTemplatePool`, `StructureProcessorList`. Новый генератор соединённых комнат с нуля не нужен.

Практический набор сейчас — **Misode для данных + WorldEdit для авторинга + ванильные шаблоны/Jigsaw для игры**. WorldEdit устанавливается только в отдельный редакторский профиль. Собственные постройки можно сохранить как `.schem`, разместить в редакторском мире и затем экспортировать ванильным структурным блоком в NBT. `.schem` не следует просто переименовывать в `.nbt`: форматы различаются. Текущий `WatchpostRuins` уже читает NBT и проверяет весь объём перед размещением.

## Ограничения именно Междуморья

`IslandChunkGenerator.createStructures` и `applyBiomeDecoration` сейчас отключают стандартные этапы. Регистрация пула или установка библиотеки сама по себе не создаст наши постройки. Для выбранного пути потребуется отдельное подключение только авторских структур и их размещения.

Обычная heightmap здесь видит технический потолок и верхний океан. Начальную площадку нужно искать по островному грунту между морями; автоматическое `project_start_to_heightmap` нельзя включать без адаптации. Для первой версии подходит абсолютная высота найденной площадки, `terrain_adaptation: none` и полный контроль размещаемых частей.

После сборки плана проверяются опоры, проходы, свободный объём, отсутствие жидкости и `landAllowed(profile,x,y,z)` для каждой клетки. Одного ограничения `min_y/max_y` недостаточно: поверхность верхнего моря зависит от X/Z. Сохраняются LEGACY 128 / TALL 256, детерминированность seed, ограниченное число попыток и отсутствие перезаписи уже загруженных чанков. Крупные структуры на несколько чанков требуют сохранённого плана и согласованного размещения, а не записи соседнего чанка из нынешней `buildSurface`.

## Что не подключать автоматически

- **Structure Gel API:** [официальные метаданные](https://api.modrinth.com/v2/project/structure-gel-api) отмечают All Rights Reserved; список выпусков содержит 1.20.4 и 1.21.4, но [фильтр NeoForge 1.21.1](https://api.modrinth.com/v2/project/structure-gel-api/version?game_versions=%5B%221.21.1%22%5D&loaders=%5B%22neoforge%22%5D) пуст. Это не готовая открытая библиотека для нашей версии.
- **Recurrent Complex Volts:** [0.7.3.0 для NeoForge 1.21.1](https://api.modrinth.com/v2/version/wuQ1vWhy) существует и умеет настраиваемые структуры, но [GitHub](https://github.com/Akiak7/RecurrentComplexVolts#building-from-source) содержит только документацию. [Лицензия автора](https://gist.github.com/Akiak7/83dbc748a362058ddaef2560bd4a94e3) закрывает современные изменения и ограничивает распространение. Рассматривать отдельный мод можно; использовать как открытую исходную библиотеку нельзя. Старый оригинальный Recurrent Complex не доказывает совместимость современного порта.
- **TerraBlender:** [4.1.0.8 Beta для NeoForge 1.21.1](https://modrinth.com/mod/terrablender/version/6e8GCrLb), LGPL-3.0, помогает согласовывать биомы, но не строит острова, деревья или руины. У нас уже собственный `MultiNoiseBiomeSource`; отдельная потребность пока не установлена.

## Следующий ограниченный эксперимент

В одноразовом редакторском мире сделать собственные 3–5 модулей убежища, соединить ванильным Jigsaw и настроить пул через Misode. Затем в отдельном проверочном профиле подключить только эту структуру к генератору, проверить реальные новые чанки обоих профилей, приливное укрытие, негативные координаты, порядок генерации и холодный перезапуск. Это даст доказательство пригодности готового механизма до добавления новой обязательной библиотеки.
