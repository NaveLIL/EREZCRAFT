# Задания для ИИ по разработке Междуморья

Использовать вместе с [дорожной картой](IMPLEMENTATION_ROADMAP.md). Каждая строка ниже — отдельная задача, а не обещание реализации за одно сообщение. Все задачи на момент создания документа запланированы. Идентификатор задачи определяет границу работы; блокирующая зависимость должна иметь проверенный результат.

## Общий промпт исполнителю

Скопировать этот блок и добавить идентификатор нужной задачи из таблицы.

```text
Работаем над Междуморьем: Minecraft Java 1.21.1, NeoForge 21.1.252, Java 21.

Прочитай применимые AGENTS.md, IMPLEMENTATION_ROADMAP.md, AI_TASKS.md и документы,
относящиеся к выбранной задаче. Проверь текущее состояние исходников и результаты
её зависимостей. Существующие отчёты отличай от нового прогона.

Выполни только задачу, указанную в конце этого промпта, и необходимые для неё
небольшие исправления. Сохрани принятый замысел, текстуры и работоспособность
остальных измерений. Не переписывай весь проект и не обновляй Minecraft,
загрузчик или сторонний мод без конкретной зависимости от этой работы.

Сначала найди реальные точки изменения и подтверди используемые API по
зависимостям проекта и документации 1.21.1. Названия будущих классов в плане
не означают, что такие классы или методы уже существуют.

Реализуй рабочее поведение, запусти подходящие проверки и исправь обнаруженные
проблемы в пределах задачи. Если сложной задаче нужны несколько изменений,
выполняй их последовательно с отдельной проверкой каждого.

Сохраняй пользовательские изменения. Используй отдельные тестовые миры.
Не удаляй и не перестраивай существующие игровые сохранения. Обычный мир,
Незер и Энд не должны получать наши эффекты или заражение. Не заменяй изоляцию
глобальным выключением инфекции. Внутри Междуморья она развивается свободно.

Игровое состояние определяет сервер. Сохранение, выход и повторный вход,
смена измерения и выделенный сервер входят в проверку там, где они существенны.
Для визуальных изменений нужны кадры из игры; для сетевого поведения игрока —
соответствующий клиентский сценарий. Компиляция не доказывает этих свойств.

Не заявляй о пройденной проверке без её результата. Не помечай функцию готовой,
если вместо неё остаётся заглушка или лишь регистрация. Если обязательная
проверка недоступна, зафиксируй точную причину и не меняй критерий готовности.

После завершения создай или обнови docs/progress/<ID>.md: что сделано,
какие файлы изменены, команды и результаты, пути отчётов, статус ручной
приёмки, оставшиеся риски и готовность следующей задачи. При наличии Git
проверь diff; коммит, публикацию и push выполняй только в согласованном режиме.

Не переходи автоматически к следующему ID. Заверши ответ результатом
выбранной задачи и фактическими проверками.

Задача: <вставить ID>
```

Папка `docs/progress/` и её отчёты появятся при выполнении задач. Их отсутствие сейчас не означает существование незаписанных результатов.

## Уточнения для задач с высоким риском

### M00 Исходная версия

```text
Выполни M00. В предыдущей проверке папка не была Git-репозиторием.
Сначала установи фактическое состояние: не предполагай существующую ветку.
Подготовь локальную исходную точку и исключения для build, run, сохранений,
кешей и сторонних исследовательских файлов. Перед включением файлов
проверь состав; не делай git add . без просмотра. Ничего не публикуй.

Проверь Java 21 и зафиксированные Minecraft 1.21.1 / NeoForge 21.1.252.
Выполни существующие build и GameTests, затем подходящий smoke отдельно.
Разбери реальный результат каждой команды. Не изменяй игровую механику.
Если проверка падает, установи причину и отдели дефект исходной версии
от проблемы окружения. Сохрани отчёт M00 и способ воспроизведения.
```

### M02 Проверяемая изоляция инфекции

```text
Выполни M02 после принятой M01. Используй оригинальную закреплённую версию
стороннего мода только в отдельном тестовом профиле. Прочитай существующее
исследование, но проверь каждый использованный вывод по фактическому артефакту.

Найди пути появления, изменения блоков и биомов, заражения сущностей,
смерти, эффектов, активных предметов, снарядов, переноса и отложенной работы.
Установи проверку по ключу affected Level, а не по имени биома или месту
хранения глобального состояния. Не считай фильтр естественного спавна
полной изоляцией. Учти прямые записи, которые обходят обычные события.

Внутри целевого измерения покажи реальное распространение и развитие.
Снаружи проверь нормальные измерения и дополнительное тестовое. Сравнивай
инфекционные изменения, не требуй полной неподвижности обычного мира.
Проверь save/reload и отложенные действия. Представь точные точки интеграции,
тестовую матрицу, остающиеся неизвестные и решение: кандидат подходит,
нужна дополнительная проверка или нужен другой кандидат.

Не устанавливай экспериментальный мод в обычный игровой профиль.
```

### M03 и M04 Общая геометрия

```text
Выполняй только выбранную задачу M03 или M04. SeaSurface сейчас разделяется
генерацией, отрисовкой, выделением и расчётом контакта. Найди всех потребителей.
Не изменяй одни глобальные высоты так, чтобы молча преобразовать лаборатории.

M03 сначала выделяет профиль с прежним результатом. M04 только после проверки
M03 добавляет новый высокий профиль в отдельном новом сохранении.
Учти границы мира, циклы генерации, NoiseColumn, heightmaps, поиск посадки,
объём жидкости, погружение камеры и параметры, необходимые клиенту.
Проверь сериализацию и явно опиши поведение старых данных без поля профиля.
Не обещай совместимость изменения высоты существующего сохранения без
отдельной миграционной проверки. Пользовательские миры не перестраивай.
```

### M07 Подъём и настоящие укрытия

```text
Выполни M07 после M06. Добавь ограниченную плавную подъёмную силу с корректным
затуханием. Проверь движение настоящего игрока на выделенном сервере;
автотест сущности не доказывает поведение ServerPlayer и клиентского движения.

Не используй canSeeSky или верхнюю heightmap как готовый детектор укрытия:
над всем измерением расположены токсичное море и техническая оболочка.
Ищи подходящую крышу между игроком и реальной нижней поверхностью моря.
Проверь искусственную крышу, стекло, плиту, листву, отверстие, навес на краю,
разрушение крыши и перемещение между колонками. Исключи жидкость и оболочку.

Не сбрасывай глобально fallDistance и не отключай проверки полёта на сервере,
чтобы скрыть дефект. Проверь штатное падение, лестницы, воду, транспорт,
элитры и смену измерения. Измерь стоимость проверки укрытий до оптимизации.
```

### M12 Первая полная экспедиция

```text
Выполни M12. Создай отдельный survival-профиль с точными настройками и seed.
Проверь весь пользовательский путь: рецепт портала из внешних ресурсов,
вход, распознавание цели, предупреждение прилива, укрытие, получение
компонента, нормальный выход, создание и применение индикатора.

Не пользуйся административными командами для закрытия этого критерия.
Служебные команды в диагностике отмечай отдельно. Сохрани длительность,
смерти, непонятные места, причины возврата и найденные обходы прогрессии.
Покажи кадры ключевых мест. Исправь блокирующие дефекты маршрута.
После технической проверки оставь явный статус игровой приёмки владельцем.
```

## Формат отчёта задачи

```text
Задача и статус:
Исходная версия / контрольная точка:
Результат для игрока:
Изменённые файлы:
Команды, коды завершения и краткие результаты:
Тестовый профиль, seed, настройки и зависимости:
Пути логов / отчётов / игровых кадров:
Непроверенные обязательные сценарии:
Решение владельца, если нужна игровая или художественная приёмка:
Оставшиеся дефекты и готовность зависимых задач:
```

Сложную задачу делить по результату: например, состояние и сохранение устройства, затем воздействие, затем сеть и приёмка. Каждый подпункт заканчивается проверкой. Не делить по принципу «сегодня все классы, потом когда-нибудь всё заработает».

Плановые оценки сложности не определяют модель автоматически. Для геометрии, сетевой физики, совместимости сохранений и интеграции инфекции нужен особенно тщательный разбор и проверка; рутинные данные и оформления можно выполнять после появления принятого образца. Конкретные модели, лимиты и тарифы не являются предпосылкой этой карты.
